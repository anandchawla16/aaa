## What every module inherits from Module 1

These are used verbatim throughout and are not re-taught:

- **Trust tiers** — T1 read it · T2 spot-check · T3 verify arithmetic ·
  T4 ground it or don't answer · T0 don't.
- **CRISP** — Context · Role · Inputs and source of truth · Steps and
  refuse-to-guess · Product and acceptance criteria.
- **VFRR** — Priority = (Volume + Friction + Readiness) − Risk.
- **Three Lanes** — Draft · Decide-support · Never.
- **The habit** — "How would I know if that were wrong?"
- **Defect report before analysis.** Every module. Every new export.

## Standing structure

Each module runs the same shape, which participants come to rely on:

| | |
|---|---|
| 0:00 | Commitments review — every participant reports their 30-day workflow status in 90 seconds, including what has not happened |
| 0:15 | Teaching block |
| | Exercises with debriefs, alternating |
| −0:15 | Commitment update and close |

The opening commitments review is not ceremonial. It is the mechanism that
stops the programme becoming a series of enjoyable workshops that change
nothing. Participants who have done nothing say so, in front of peers, every
time — and it works.
