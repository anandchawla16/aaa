# Setup Checklist

---

## One week before

- [ ] Confirm 6–12 participants, ideally spanning all five functions.
- [ ] Confirm every participant has a working Claude account and can upload a
      file. **Test this individually — do not assume.** A participant
      discovering an access problem at 0:38 costs the room twenty minutes.
- [ ] Send the pre-read: [`01-role-charter.md`](01-role-charter.md) and
      [`../data/group-fact-sheet.md`](../data/group-fact-sheet.md). Nothing else
      — the rest lands better cold.
- [ ] Ask each participant to bring one sentence: *the task in my week I would
      most like to stop doing.* Used in Ex 1.0 and Ex 1.1.
- [ ] Invite the Group IT/compliance representative as an observer. If they
      cannot attend Module 1, brief them separately on the Never List before
      Module 5.
- [ ] Book the room for **5 hours 15 minutes** — the run sheet is 5:00 and
      every cohort needs the margin.

## Two days before

- [ ] Distribute the data pack, or confirm participants can reach
      [`../data/`](../data/). Files are needed locally to upload.
- [ ] Confirm the exact file list is reachable:

| File | Used in |
|---|---|
| `group-fact-sheet.md` | Ex 1.1 |
| `hr-service-and-leave-policy.md` | Ex 1.2, 1.3, 1.4 |
| `accounts-fee-policy-circular.md` | Ex 1.4 |
| `purchase_requisition.csv` | Ex 1.5 |
| `purchase_vendor_quotations.csv` | Ex 1.5 |
| `marketing_admission_enquiries.csv` | Ex 1.6 |
| `marketing_channel_spend.csv` | Ex 1.6 |
| `academic_assessment_results.csv` | Ex 1.6 (optional) |
| `hr_staff_roster.csv` | Module 2 |
| `accounts_fee_ledger.csv` | Ex 1.2 stretch, Module 3 |
| `purchase-requests-inbox.txt` | Module 3 |

- [ ] Print or share: the workbook, the eight exercise briefs, the rubric.
- [ ] Read the answer key yourself, fully. In particular, be able to state from
      memory: the eleven-month probation, the deemed-confirmation rule, the
      mid-session relieving bar, the GST-basis reversal in Ex 1.5, and the 75%
      channel overstatement in Ex 1.6.

## Morning of

- [ ] Whiteboard, permanently visible for the whole session:

```
   TRUST TIERS      T1 read it · T2 spot-check · T3 verify arithmetic
                    T4 ground it or don't answer · T0 don't

   CRISP            Context · Role · Inputs & source of truth
                    Steps & refuse-to-guess · Product & acceptance

   VFRR             Priority = (Volume + Friction + Readiness) − Risk

   THREE LANES      1 Draft · 2 Decide-support · 3 Never

   THE HABIT        "How would I know if that were wrong?"
```

- [ ] Second whiteboard or flipchart kept blank, headed **"Things we found
      today."** Write on it every time a participant catches a defect or an
      error. By 5:00 it should be full. It is the most persuasive artefact in
      the room and costs nothing.
- [ ] Water, and real breaks. This is 4.5 hours of concentration.

## In the first two minutes

State these three things before anything else:

1. **The synthetic-data rule.** Nothing real goes into anything today, or before
   Module 5. This is enforced and it affects certification.
2. **The Never List.** Read all seven items aloud. Do not summarise them.
3. **The habit.** "How would I know if that were wrong?" — and that you will be
   asking it all day, including about work that is correct.

## Technology fallbacks

| Problem | Fallback |
|---|---|
| A participant cannot upload files | Pair them. The reviewer role is genuinely the harder half — say so, so it does not feel like a demotion. |
| Network fails for the room | Ex 1.1 Step 1–2, Ex 1.2 Part A, and Ex 1.7 all work on paper. Ex 1.5 and Ex 1.6 do not — move them and extend the debriefs. |
| Outputs differ noticeably between participants | Expected and useful. Use it: "three of you got different totals from the same file. Which is right, and how would you tell?" |
| A participant's output is much worse than the room's | Almost always a missing file or an unattached upload. Check that first. |

## Materials the participant leaves with

- [ ] Eight completed exercise deliverables
- [ ] A signed, dated 30-day commitment with a named owner
- [ ] The quick reference card from the back of the workbook
- [ ] A photo of the "Things we found today" board

## After the session

- [ ] Mark within 48 hours against the answer key's exact figures.
- [ ] One sentence of feedback per participant. One, not a paragraph.
- [ ] Chase every commitment at **day 7** — this single follow-up produces more
      of the programme's value than any other post-session action.
- [ ] Schedule resubmissions for anyone below the Ex 1.8 floor before Module 2.
